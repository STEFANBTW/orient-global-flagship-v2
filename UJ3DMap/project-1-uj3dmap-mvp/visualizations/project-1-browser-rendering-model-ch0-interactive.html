Browser Rendering Pipeline

Bytes → Tokens → DOM → CSSOM → Layout → Paint

1. The 7-Phase Architecture Idle
1
Bytes → Characters
TCP socket delivers raw bytes. Decoded via UTF-8.
GET /index.html → 4,301 raw bytes
↓
2
Tokens → DOM Nodes
Blink HTML parser builds the DOM tree.
<div id="map"> → HTMLDivElement
↓
3
CSS → CSSOM
CSS parsed into a tree of StyleRule objects.
#map { height: 100vh } → LayoutBox
↓
4
Render Tree
DOM + CSSOM merge. Invisible nodes excluded.
HTMLDivElement + {height:100vh} → LayoutBlock
↓
5
Layout (Reflow)
Calculate exact pixel dimensions/positions.
div#map → x:0 y:56 w:1440 h:956
↓
6
Paint + Composite
GPU Process rasterizes display lists.
drawRect(0,56,1440,956,#090b10)
↓
7
V8 Execution
DOMContentLoaded triggers V8 JS engine.
L.map('map') → map instance
2. DOM Construction (Blink) Awaiting HTML
<html>
<head>
<link rel="stylesheet" href="style.css">
<body>
<div id="map"></div>
<script type="module" src="app.js">
