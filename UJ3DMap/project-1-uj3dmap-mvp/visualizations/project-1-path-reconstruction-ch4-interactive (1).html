Path Reconstruction State Machine

Reversing cameFrom pointers to construct optimal graph path via array unshift

1. Graph Pointer Trace (cameFrom) Ready
2. Reconstruction Logic Idle
function reconstructPath(cameFrom, current) { const path = [current]; // Init array with target while (cameFrom.has(current)) { current = cameFrom.get(current); path.unshift(current); // Insert at index 0 } return path; }
3. Heap State: Pointer Map & Output Array Waiting
Map: cameFrom (Backpointers)
Array: path (Output Buffer)
