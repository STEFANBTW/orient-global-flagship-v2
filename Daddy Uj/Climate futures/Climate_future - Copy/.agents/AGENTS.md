# Agent Rules

- **Project Completion Links**: Always provide a clickable link to view the final result (e.g., the local development server URL) after completing work on a project.
- **Browser Inspection**: Never open the browser to inspect the page automatically. Leave inspecting and testing in the browser to the user to do manually.
- **Line Numbers**: Whenever the user asks where a control or code implementation is located, always provide the exact line number(s) along with the file path.
